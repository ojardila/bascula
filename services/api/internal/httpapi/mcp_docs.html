How it works

Transport: .

Each tool is a Báscula API route under another name. A call re-enters the API as the caller, so the permission table, the farm and row-level security apply exactly as in the app: a tool answers according to the role in the token and returns FORBIDDEN otherwise.

Money is in integer cents; dates are YYYY-MM-DD in the farm's time zone. Tools marked two-step write nothing on the first call: they return a preview and a confirmationToken; a second call with the same arguments and that token executes.

Authentication

Send Authorization: Bearer <access token>. The token is a Báscula session for one farm and one role. ChatGPT and Claude obtain it with OAuth 2.1 (authorization code + PKCE) — discovery at /.well-known/oauth-protected-resource. For a script, sign in with POST /v1/auth/login and use accessToken (valid 15 minutes).

Roles: owner admin weigher. The weigher never sees money.

Try it — your token

Paste an access token to run tools from this page. It is kept only in this tab and sent only to /mcp on this host. Calls run for real, with your role, on your farm.
